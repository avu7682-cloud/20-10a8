## 🚀 Cách Deploy lên GitHub Pages

### Bước 1: Tạo Repository trên GitHub
1. Đăng nhập vào [GitHub](https://github.com)
2. Nhấn nút **"New repository"** (màu xanh lá)
3. Đặt tên repository: `10a8-women-day-2025` (hoặc tên bạn muốn)
4. Chọn **"Public"** để website có thể truy cập được
5. Tích chọn **"Add a README file"**
6. Nhấn **"Create repository"**

### Bước 2: Upload Files
1. Trong repository vừa tạo, nhấn **"uploading an existing file"**
2. Kéo thả hoặc chọn tất cả các files:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`
3. Viết commit message: `🌸 Add Vietnamese Women's Day website for class 10A8`
4. Nhấn **"Commit changes"**

### Bước 3: Kích Hoạt GitHub Pages
1. Trong repository, nhấn tab **"Settings"**
2. Cuộn xuống phần **"Pages"** ở sidebar bên trái
3. Trong **"Source"**, chọn **"Deploy from a branch"**
4. Chọn branch **"main"** và folder **"/ (root)"**
5. Nhấn **"Save"**

### Bước 4: Truy Cập Website
- Sau 2-3 phút, website sẽ có sẵn tại: `https://[username].github.io/[repository-name]`
- Ví dụ: `https://yourname.github.io/10a8-women-day-2025`
